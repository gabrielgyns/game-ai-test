# Modelos .vox

Arquivos `.vox` do [MagicaVoxel](https://ephtracy.github.io/) salvos aqui substituem os modelos do
cenário esculpidos por código. O nome do arquivo é o id do modelo (`carvalho-1.vox`, `pilar.vox`...);
os ids aparecem na descrição de cada adereço no lab (`/lab.html`).

- Escala: 1 voxel do editor = 1/12 m no jogo (um carvalho tem uns 55 voxels de altura).
- Eixos: Z do editor é para cima; a vista Front do editor é a frente do modelo no jogo.
- Para partir de um modelo do jogo, abra-o no lab e clique em **Exportar .vox**.
- O jogo monta sozinho os três níveis de detalhe a partir do arquivo.
